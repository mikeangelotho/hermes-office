# Office / signal tape — implementation contract

One desktop install, no gateway changes. Command/Inspect surface over the current campus: a quiet entry, a time ruler with three **real** signals (presence, tool pulse, observed links); always an explicit return to live. Last hour on the transport, older recorded hours by time. Never invent the hour before first capture. No video recording.

## Wire and disk

`src/domain/trace.ts` (lead) exports `TraceActor {id:string; kind:'profile'|'session'|'subagent'; team:Team; state:AgentState; signal:'presence'|'tool'; parentId?:string}`, `TraceFrame {atMs:number; coverage:'verified'|'partial'|'unknown'; actors:TraceActor[]}`, `TraceWindow {version:1;startMs:number;endMs:number;cadenceMs:number;firstMs:number|null;lastMs:number|null;frames:TraceFrame[]}`, `SceneTape {atMs:number; rate:number; actors:readonly TraceActor[]}`, `TRACE_WINDOW_MS=3600000`, `TRACE_CADENCE_MS=15000`, `TRACE_HOLD_MS=35000`. Times are UTC Unix integer milliseconds, speed signed relative to wall time. Actor IDs are existing validated `p-` + 32 lowercase hex for participants, `r-` + 32 hex for pseudonymized aggregate rows. Parent only if both observed and same frame, no imaginary collaborators; never count a profile in addition to its detailed people. Never store or send names, text, session keys, command/tool names or argument/result strings in the tape; `tool` means the native numeric tool-call counter increased between adjacent verified samples; NOT a particular tool, task or spoken sentence. Unknown frame has no actors. Account for missing field/table, unavailable bridge, stale/gap, partial coverage, counter reset and sleep/restart. Presentation annotations use a local fixed vocabulary, explicitly illustrative; no external model/requests/assets.

Server owns recording every ~15s while **desktop launcher** runs even without tabs. Archive under user-only local app data (`%LOCALAPPDATA%/Hermes Office/recordings.sqlite3` on Windows), outside repo/static roots, retained beyond one hour until user deletes it; compact repeated state on disk if practical. Sample a strict projection; no raw observation JSON persisted. Return same shapes from `GET /api/office/history` (rolling past hour), `?end=E` (hour ending at E, clamp future, no destructive API), and `?after=A` (incremental rolling-hour response; may include one predecessor; startMs always endMs-1h). At most one predecessor within hold of start/after for continuity. firstMs/lastMs are available whole-archive extrema. Use existing exact-origin policy, no-store, CORP; enforce actual loopback **socket peer** on both private routes. Do not start recorder on wildcard dev servers; dev/QA recording off unless explicitly run as guarded desktop with isolated `OFFICE_HISTORY_DIR`. No archive writes to repo, test fixtures or public route. Local history errors must not break existing live feed. Internal `python -I -B bridge/collect.py --recording` yields `{snapshot:<existing public validated OfficeSnapshot>,meters:{<qualified p-ID>:<safe integral nonnegative counter>}}` (default invocation shape/privacy unchanged); missing counter is absent, never guessed. No new SQL reads except optional sessions.tool_call_count for verified current workers. Capture time or `observedAt` must not pretend a stale observation is fresh.

## Windows archive permissions

At desktop startup, create a new Office archive folder with file-inheritable permissions for the current user, SYSTEM and local Administrators. Verify the folder, existing database, and any rollback journal, WAL or SHM before opening SQLite. If privacy cannot be verified, leave existing files and permissions alone: history is unavailable, but live status stays independent. These are local file permissions, not encryption; an exported JSON file is governed by its destination.

## Client boundaries

Lead supplies `src/lib/trace-player.ts`: `createTracePlayer(eligible:()=>boolean, opened:()=>boolean)` exposes accessors `window():TraceWindow|null`, `frame():TraceFrame|null` (valid at cursor, unavailable/gap remains unknown), `cursorMs():number`, `rate():number`, `live():boolean`, `archived():boolean`, `loading():boolean`, `error():string|null`, `tape():SceneTape|undefined`, `fullWindow():TraceWindow|null` (the exact fully fetched selection, still usable during an incremental read but not after an archive replacement), `completeHour():boolean` (the selected hour is validated and ready for a local JSON export), and methods `seek(ms)`, `play(signedRate)`, `pause()`, `goLive()`, `openArchive(endMs)`, `refresh()`. `goLive` synchronously uses separately kept latest observation; old/slow archive calls cannot overwrite it; viewer may exit to live. While closed only a short tail is needed, while open use entire newest hour + incremental updates; do not refetch entire hour on every tick. If recorder unavailable use original live mode (no synthetic substitution); empty/gaps represented distinctly. Demo, embeds and legacy hero never request history or live data; lifecycle cancels poll/requests on ineligible or hidden and resyncs on resume. `src/domain/trace.ts` exports `traceAgents(frame:TraceFrame|null):OfficeAgent[]` with neutral illustrative labels, and `traceLabel(actor:TraceActor):string`. Lead supplies both before full build.
